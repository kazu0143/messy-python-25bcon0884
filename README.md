Student Marks Report Generator 🐍
A simple Python program that calculates student marks, assigns grades, computes the class average, and identifies the topper.

📌 Project Description
This project demonstrates basic data processing and conditional statements in Python.

The program stores student names and their marks in a list. It calculates each student's total marks and average, assigns a grade based on the average, calculates the overall class average, and identifies the student with the highest average.

🔍 How It Works
Student Data: Stores the names of five students along with their marks in three subjects.
Total Marks: Uses a function to calculate the sum of each student's subject marks.
Grade Assignment: Assigns grades based on the student's average.
Class Average: Calculates the average of all students' averages.
Topper Identification: Finds the student with the highest average.
✨ Features
Stores multiple students' marks using nested lists.
Calculates total marks and average.
Assigns grades using if-elif-else statements.
Calculates the class average.
Identifies the topper based on the highest average.
Uses loops and a function for repeated calculations.
